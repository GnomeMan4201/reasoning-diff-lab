# Quickstart (for pilot participants)

You do not need to read anything else in this repository to take part. Follow the facilitator's role and case assignment.

## Training

1. Ask the facilitator to run `npm start` and open the local link.
2. Use **Training demo — not pilot data** or click **Load the separate completed training demo**.
3. Practice the interface only with that demo. Do not open the pilot case reference paths in the repository.

## Analysts

1. Select the assigned pilot case and your role: Analyst A or Analyst B.
2. Read the evidence packet shown in the interface. Do not discuss it with the other analyst.
3. Open **Analyst Entry** and use either guided entry or prose-first assisted structuring.
4. Confirm every unit you want included, then click **Freeze and save my path**.
5. Download your path if another device will be used, then hand the device back to the facilitator.
6. Do not switch to Reviewer or try to view the other analyst's path.

## Reviewer

1. Select the same pilot case and the Reviewer role.
2. Confirm both frozen paths are present or import the Analyst A and Analyst B path files.
3. Download the prose-only baseline packet and review it **before** opening Reviewer Matching.
4. Record the baseline duration in minutes.
5. Open **Reviewer Matching**, confirm/reject/add matches, and mark contradiction only when two related statements cannot both be true.
6. Generate the report, grade every event using `docs/SCORING_RUBRIC.md`, and list important divergences the report missed.
7. Export the report and session log before changing cases or resetting the browser.

If something breaks, is confusing, or exposes information too early, say so immediately. Confusion and failure are pilot data.
