Reasoning Diff Lab

A pilot instrument for one question: does comparing two independent reasoning paths surface useful, non-obvious divergences? What is this?

What this is — and is not

  • This is pilot-ready but empirically unvalidated. No claim is made that it works yet.
  • It does not determine truth, rank analysts, or infer contradictions from wording.
  • Every automatic suggestion is a proposal a human must confirm.
  • The training demo is not pilot data.
